- 2026-09-27 · D23 · Enrolling into a **closed** cycle is allowed by the API (the spec forbids only what it states, and admin-is-god); the UI simply does not offer the action once a cycle is closed. - 2026-09-27 · D24 · `PATCH /admin/placement-cycles/{cycle}` accepts `status` so an admin can reopen a cycle closed by mistake; `close` stays the dedicated one-way action (422 when already closed). Update requires the full field set, matching Phase 1's `PolicyDocumentController@update`.
- 2026-09-27 · D25 · A bulk enrol writes **one** `cycle.enroll` audit row for the whole batch (counts + the first 100 roll numbers + a `roll_nos_truncated` flag), not one per student — a 3000-row import must not create 3000 audit rows. No audit row is written when nothing changed. Single-student `cycle.unenroll` is audited individually.
- 2026-09-27 · D26 · Blank entries in a pasted roll list are skipped rather than rejected (`roll_nos.*` is `nullable`), because the UI splits a textarea on whitespace; an all-blank payload still 422s with "No roll numbers were found in the input."
